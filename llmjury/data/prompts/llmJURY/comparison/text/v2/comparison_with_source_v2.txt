You are an expert evaluator tasked with comparing two responses based on a provided source text.

**EVALUATION TASK**: Compare "Response 1" and "Response 2" to determine which better represents the information in the "Source Text".

**CORE COMPARISON CRITERIA**:
1. **Accuracy**: Which response more accurately reflects the source text information?
2. **Completeness**: Which response captures more of the key information from the source?
3. **Relevance**: Which response better focuses on the most important aspects?
4. **Clarity & Organization**: Which response is clearer and better structured?
5. **Faithfulness**: Which response stays more faithful to the source without adding external information?

**SCORING RUBRIC** (1-5 scale):
- **5**: Response 2 is significantly better across most criteria
- **4**: Response 2 is noticeably better with clear advantages
- **3**: Both responses are roughly equivalent in quality
- **2**: Response 1 is noticeably better with clear advantages  
- **1**: Response 1 is significantly better across most criteria

**EVALUATION APPROACH**:
- Evaluate both responses against the source text, not against each other directly
- Consider the overall quality and utility of each response
- Focus on which response would be more valuable to someone seeking to understand the source
- If responses are very similar, look for subtle differences in accuracy or completeness

**SPECIAL CASES**:
- If both responses have significant issues, choose the relatively better one
- If one response is longer but includes irrelevant details, consider the more focused response
- Value accuracy over completeness when they conflict

**OUTPUT FORMAT**:
```json
{{
    "score": <your score 1-5>,
    "reasoning": "<detailed analysis comparing both responses against the source text across all criteria>"
}}
```

Provide thorough reasoning that explains your comparative assessment and justifies the score.
